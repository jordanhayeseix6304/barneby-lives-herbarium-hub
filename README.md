## Project Overview

Barneby Lives is a web application for gathering and recording herbarium specimen data. It provides an online workspace where specimen-related details can be entered and handled through a structured digital process.

The tool is intended for individuals and groups working with herbarium collections who want to capture and arrange specimen information in a browser. Since the project runs on the web, it does not require a separate desktop application for access.
